FITTRACK 77 — ANDROID INSTALLABLE FITNESS WEB APP

Included:
- Responsive fitness app designed for Android phones
- Personalized starting profile: age 21, 77 kg, 166 cm, goal 60–65 kg, sedentary IT job 9 AM–5 PM, non-vegetarian
- Diet plan, Tamil Nadu foods, cereals/millets and protein guide
- Daily routine checklist, weekly workout tracker and home strength exercises
- Weight log, progress chart, local data storage and JSON export
- PWA manifest and offline service worker

IMPORTANT:
This ZIP contains an installable Progressive Web App (PWA), not a signed Android APK. Android requires the app to be served from a secure HTTPS website before Chrome offers the install option. This ZIP alone cannot be installed by tapping it.

QUICK INSTALL METHOD:
1. Extract this ZIP on a computer.
2. Upload the files (index.html, app.js, manifest.webmanifest, sw.js, icon.svg) to an HTTPS static host, such as a GitHub Pages site. Keep all files together in the same folder.
3. Open the hosted HTTPS page in Chrome on your Android phone.
4. Open Chrome menu (⋮) and choose “Install app” or “Add to Home screen”.
5. Confirm. FitTrack 77 will appear on your home screen and can work offline after its first successful load.

You can also ask an Android developer to package these files into an APK using a Trusted Web Activity or WebView. An APK has not been built or signed in this package.

PRIVACY:
Weight entries, profile and checklists are stored in browser localStorage on your device; no server or account is used by this app. Export a JSON backup before clearing browser data.

HEALTH NOTE:
The 1,700–1,900 kcal range is a provisional starting estimate; calorie needs vary by sex, activity and health. Meal calories are approximate. This app is for wellness support, not diagnosis or medical care.
